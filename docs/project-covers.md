# Portfolio covers · September 2026

Generated with the built-in ImageGen tool. Final assets are 1448 × 1086 (4:3) WebP, encoded at quality 90. The covers are physical metaphors, not screenshots or diagrams of hardware shipped by these software repositories.

Source concepts were checked against the repositories before generation:

- [ThermoForge](https://github.com/cdexswzaq0110/ThermoForge): 2D steady-state board heat conduction and model verification, not CFD or proven acceleration over its solver.
- [Agent Kernel](https://github.com/cdexswzaq0110/Agent-System-Design): OS-inspired scheduling, isolated agent tasks, context, and supervision.
- [Indoor Positioning](https://github.com/cdexswzaq0110/Indoor-Positioning-System): camera-based landmark recognition and coordinate mapping, not radio triangulation. Geometric floor marks are a text-free visual metaphor for the repository's numeric landmarks.
- [SignalWeave](https://github.com/cdexswzaq0110/SignalWeave): four retrieval routes, explainable ranking, and constrained slate selection; evaluation uses synthetic data.

The old SignalWeave cover and Megumi cover remain available. New homepage assets:

- `assets/thermoforge.webp`
- `assets/agent-kernel.webp`
- `assets/indoor-positioning.webp`
- `assets/signalweave-v2.webp`

This is 2D steady-state conduction, not a fluid cooling or CFD system.
Subject: One low broad rectangular limestone board in a thin charcoal tray, carrying three small copper heat-source blocks in an intentionally asymmetric layout. Extremely shallow concentric rounded contour grooves spread outward from the sources across the ivory planar board, subtly copper-inlaid nearest the sources. A single frosted acrylic sheet with a corresponding soft embossed contour relief is supported just above the rear portion by four short precise metal standoffs, representing a predicted field. A compact charcoal measurement carriage on a short mechanically attached side rail holds one copper contact probe that reaches the board. Restrained, open planar composition, one believable thermal inspection instrument, no heat-sink fins or coolant pipes.

## UI direction

Applied [TasteSkill's existing-project redesign skill](https://github.com/Leonxlnx/taste-skill/tree/main/skills/redesign-skill): audit first, keep the existing stack, use precise typography, a warm consistent gallery surface, and accessible interaction states. The collection adds a sticky desktop index, a native collapsible mobile index, category controls, and explicit repository names. The cover frame keeps the full image visible rather than scaling away the margins.

The previous deployed version is commit `3e315e8`. Changes are additive to the existing site, retaining the mobile menu, reduced-motion option, and SEO verification files. Run `node tests/portfolio.mjs` for the content contract and use the browser checks in README for interface changes.
